# SpaceDock 使用说明

## 安装与启动

运行 `scripts/build.sh` 生成 `dist/SpaceDock.app` 和压缩包。运行 `scripts/install.sh` 安装到 `~/Applications/SpaceDock.app` 并打开设置。更新前先从菜单栏退出旧版；安装脚本会备份已有的同标识应用，不覆盖其他应用。

本地构建采用 ad-hoc 签名，没有 Apple Developer ID 或公证，用于当前 Mac 自用。换电脑或重新签名后可能需要重新授权。本包架构跟随构建机器，当前为 Apple Silicon；没有验证 Intel 或 macOS 13 的运行效果。

## 首次授权

点击应用内“授权辅助功能”，在系统设置中允许 SpaceDock。若列表里没有应用，用加号选择 `~/Applications/SpaceDock.app`。回到 SpaceDock 点击“重新检查”。状态显示“已启用”后才表示事件监听成功。

不要同时启用 SpaceLauncher 等使用空格作为修饰键的工具，避免两个事件过滤器争抢输入。SpaceDock 不会替你关闭其他软件。

## 应用快捷键

1. 点击“添加应用”，从本机选择 `.app`。
2. 点击按键框，按一个字母或数字。按物理键位识别，标签按美式布局显示。
3. 按住空格达到设置时长（默认 200ms），再按该键，启动或切换到应用。
4. 应用已在前台时，再按同一组合键隐藏。

每次按住空格只触发一次。短按空格会在松开时补发；快速空格加字母会按普通文字输入处理。单独长按空格的自动重复会在松开时补发，最多缓存 64 个空格事件，然后退回普通输入。需要持续按住空格操作的游戏或远程桌面，应加入排除列表。

## 暂停、排除与开机启动

菜单栏可暂停/恢复、打开设置和退出。设置中的“在这些应用中暂停快捷键”适用于游戏、远程桌面等；列表只影响按键识别。开机启动使用系统登录项，状态以系统实际允许的结果为准。

系统安全输入开启期间，SpaceDock 会暂停快捷键识别并尽力透传。安全输入检测按周期刷新，不能保证任意第三方输入法和安全输入切换瞬间都无差异。

## 配置与恢复

配置位于 `~/Library/Application Support/SpaceDock/config.json`，包括应用映射、长按时间与排除列表，不记录键盘文本。保存使用原子写入。

损坏或不支持的配置不会被自动覆盖，快捷键将停止。可先在设置中查看文件，或使用“备份并重置”。备份与原文件位于同一目录。

## 验收边界

状态机测试和应用构建不能代替真实输入验收。首次使用重点确认：中文选词、英文快速输入、Finder 空格预览、微信两个桌面往返，以及暂停后输入完全正常。异常时立即使用菜单栏暂停或退出，再调整阈值或排除应用。


## 在当前桌面唤起

在“应用快捷键”列表开启对应应用的“在当前桌面唤起”。SpaceDock 会检查桌面分配，必要时尝试通过 Dock 菜单设为“无”；操作过程中可能短暂显示菜单。无法确认时，按提示手动设置 Dock → 选项 → 分配给 → 无，然后重新开启。

按快捷键将主窗口搬到当前普通桌面并唤起；切走时窗口留在原处，再按可搬过来。在当前桌面前台再次按则隐藏。全屏窗口暂不支持，独立聊天窗口不会一同搬移。关闭开关后恢复普通应用唤起，不恢复之前的 Dock 分配。

旧版“切换桌面后隐藏”已移除；旧绑定的快捷键保留，尚未开启当前桌面唤起的应用可自行开启。
