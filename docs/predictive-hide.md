# 预测性隐藏实验（已放弃）

状态：用户实测效果不稳定，已放弃。相关代码已移出仓库；以下只保留实验历史，不描述当前产品。

2026-11-06：用户接受预测，随后确认实际使用外接 Magic Trackpad。

实现读取 MultitouchSupport 的触摸帧；独立辅助进程枚举连接的触摸设备，通过 refcon 为每个设备保留独立状态和锁。只有四个接触点均向同一水平方向移动超过归一化宽度 3.5%，且横移超过纵移两倍时触发。每次完整接触最多一次；抬起手指后重新准备。只向主进程传送固定协议字符串，不记录触点、按键或屏幕内容。

检测只预测意图，不证明桌面已切换。取消滑动、到达边缘仍可能隐藏，不自动恢复。仅处理通过 SpaceDock 唤起且开启自动隐藏的应用。默认关闭；失效时保留原桌面通知路径。辅助进程退出不反复重启，重新开关实验功能可重试。运行后新连接设备需重新开关功能；蓝牙重连、睡眠恢复仍需实测。

私有 ABI 参考：https://github.com/calftrail/TrackMagic/blob/master/MultitouchSupport.h
