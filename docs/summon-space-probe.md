# 当前桌面唤回：独立验证

2026-11-06，macOS 27.0.1；不改 SIP、不注入 Dock、不安装第三方窗口管理器。

用户期望：Space + W 将微信窗口搬到当前桌面并激活，人留在当前桌面。微信 Dock 分配为“无”。先验证，暂未接入主程序。

旧 Hammerspoon 兼容路径失败：目标桌面 3，窗口桌面 4；SLSSpaceSetCompatID 返回 2158019，因此没有继续调用窗口搬移，也没有激活微信。错误数值含义未确认，不能将其直接解释为权限不足。

参考 Hammerspoon PR #3889 的桥接路径后，独立测试于本机定位到操作入口。测试窗口发起搬移，等待 1 秒读回：窗口桌面由 4 变为 363，当前桌面保持 363。随后激活微信，再独立读回：当前桌面和微信窗口桌面均为 363。桌面标识为系统内部 ID，不是用户看到的桌面序号。此次系统状态验证通过；视觉效果待用户确认。多窗口、多显示器坐标、冷启动、快速连续唤回、全屏场景尚未验收。

历史原型已在清理时移出项目，保留在工作空间历史快照中。界面按钮显式发起操作，仅在实际读回窗口归属符合目标后激活。它选择面积最大的普通微信窗口，仅用于验证，不作为正式窗口选择策略。
