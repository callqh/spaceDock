# 页面设计 v0.5

日期：2026-11-06。以下是历史 HTML 设计原型，保留用于说明已确认的视觉方向，不描述当前功能。原生版本已移除“桌面切换”页和自动隐藏选项，当前页面行为以使用说明为准。

## 页面与主要动作

| 页面 | 目的 | 主要动作 |
|---|---|---|
| 应用快捷键 | 一眼看到应用、按键及自动隐藏状态 | 添加应用；行内开关；菜单中编辑/移除 |
| 桌面切换 | 解释唤起后切换桌面为何会隐藏，以及全局隐藏的影响 | 调整微信自动隐藏 |
| 偏好设置 | 展示长按阈值候选值和授权状态 | 调节等待时间；演示权限状态 |
| 菜单栏面板 | 快速确认工具状态并暂停或恢复 | 暂停/恢复、打开设置 |
| 添加/编辑弹窗 | 配置应用及单键，定位重复绑定问题 | 保存快捷键 |

应用快捷键页只预置用户实际讨论的微信 W。添加弹窗内 Safari、访达、备忘录明确是示例，不视为用户已确认映射。所有绑定更改仅在本次网页内存中生效，刷新复原，不读取或保存本机应用配置。

桌面页用并列的“唤起”和“切换”图示说明动作，另用正文说明：隐藏全应用、独立聊天窗口也受影响、回到旧桌面需再次唤起。没有展示不可保证的逐桌面置底能力。

## 预览操作与边界

直接打开 [design/index.html](../design/index.html)，或在项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory design` 后访问本机页面。没有打包步骤；重新生成 token 样式使用 `python3 design/build_preview.py`。

预览工具栏的主题选择、菜单栏面板按钮，以及权限页“模拟已授权/未授权”均为设计审阅辅助，不是已批准的产品功能。原型不消费 Space 组合键、不打开真实应用、不请求辅助功能权限、不切换系统桌面。顶栏、底栏明确说明预览性质。

- 浅色、深色、应用快捷键、桌面切换、偏好设置、菜单栏截图。
- 添加和编辑绑定；重复按键提示；移除绑定后空状态与重新添加。

截图供人工视觉检查；自动交互通过不能证明原生快捷键、微信窗口行为、权限申请或 VoiceOver 已通过。内置浏览器连接超时，视觉检查改用独立本机 Chrome，不依赖用户的浏览器会话。

## 视觉复核

保留长空格键作为唯一强调造型；移除原稿重复卡片。把窗口宽度收敛到 820px，使列表与设置保持工具尺度。无绑定的空状态优先给添加入口，失败明确提示被占用的键，避免用情绪性提示代替下一步。

最后的限制：聊天图标是占位符；预览使用独立 HTML，真实系统字体指标、材质、焦点环和窗口控件需原生实现时对齐。这里的深浅主题与 390px 适配属于设计验证，不扩展发布平台。

## v0.3 材质调整

根据用户要求改为更接近 Mac 原生半透明材质，保留原有信息架构。新增减少透明度预览，重拍所有页面截图；检查浅/深色、390px 无溢出、弹窗与菜单材质、减少透明度回退。交互仍为本地原型。

## v0.4 配色调整

保留布局和交互，主操作改为青绿，W 键帽使用杏橙，玻璃背景改为薄荷与蜜桃。更新浅/深色、菜单、弹窗及窄屏截图；检查减少透明度回退与新增键帽色对。

## v0.5 Apple 风格调整

参照 Apple 材质与 Liquid Glass 指南，导航与浮层保留玻璃，正文使用不透明中性分组。侧栏加入小型彩色图标；大键帽改为紧凑说明；应用列表与工具栏组成一个分组。保持现有功能与所有控件标识，重新检查主题、窄屏、绑定冲突及暂停/权限状态。v0.2–v0.4 的样式描述属于历史记录，当前规范以 design-tokens.md 为准。
